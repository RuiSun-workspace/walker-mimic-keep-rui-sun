## How to rebuild the film

See `BUILD-PROMPT.md`. In short: record a take from an isolated copy of tag `a7`, then run `build/build_reel.py`,
the toolkit's `generate_audio_kokoro.py`, `build/cut_clips.py`, `build/make_stills.py` and the toolkit's
`compile.py`. Everything runs locally; nothing is generated by a paid service.
