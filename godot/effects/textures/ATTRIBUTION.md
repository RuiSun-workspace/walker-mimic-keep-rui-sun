# Particle textures — credits (Assignment 6)

All three particle textures are generated by code in this repository. None is downloaded, and none
is produced by an image-generation model.

| File | Size | Used by | Made by |
|---|---|---|---|
| `soft_dot.png` | 16×16 | Effect A flash (A1), Effect B embers (B1) | `_soft_dot()` in `godot/tools/make_particle_textures.gd` |
| `straw_chip.png` | 4×12 | Effect A straw (A2) | `_straw_chip()` in the same script |
| `smoke_dot.png` | 32×32 | Effect B smoke (B2) | `_smoke_dot()` in the same script |

The script was written by agent sessions (`claude -p`, Claude Opus 5.5): session 2 (`2f5a871`) for
the first two, session 5 (`df6937c`) for `smoke_dot.png`. Texture sizes and paths come from Rui's
CHANGE-BRIEF.md §3. Regenerate with:

```bash
godot --headless --path godot --script res://tools/make_particle_textures.gd
godot --headless --path godot --import
```
